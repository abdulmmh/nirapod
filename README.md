# Nirapod - National Tax Management System

## Overview

Nirapod is a full-stack tax and revenue management platform designed to digitize taxpayer registration, tax return submission, audit management, appeals, payments, VAT administration, and related government tax services.

This repository contains the complete Nirapod ecosystem.

## Project Structure

```text
nirapod/
├── backend/       # Spring Boot REST API
├── frontend/      # Angular Web Application
├── android-app/   # Native Android Application (Java)
```

## Technology Stack

### Frontend

* Angular

* RxJS

### Mobile Applications

#### Native Android

* Java
* Android Studio
* Retrofit


## Key Features

* Taxpayer Registration (TIN)
* Income Tax Return (ITR)
* VAT Registration and Returns
* Audit Management
* Appeal Management
* AIT Management
* Tax Clearance Certificates
* Notice & Notification System
* Payment Management
* Reporting & Analytics
* Role-Based Access Control
